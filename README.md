# Wordmap analys

Локальная программа исследует семантику через официальные API Яндекса, хранит всё в SQLite и создаёт автономный HTML-отчёт.

## Запуск

1. Выполните `npm ci`.
2. Скопируйте `.env.example` в `.env`.
3. Вставьте единый Yandex Cloud API key и Folder ID.
4. Измените `input.txt`: строки — запросы, `#` — комментарий, `@brand Имя` — бренд.
5. Выполните `node main.mjs` (в Windows можно открыть `START.cmd`).
6. Откройте `results/<timestamp>/report.html`.

`Ctrl+C` безопасен: база закрывается, а повторный запуск продолжает незавершённый run с тем же `input.txt`. Каталог `results/` полностью исключён из Git. Файл `research.sqlite` — единая истина исследования.
